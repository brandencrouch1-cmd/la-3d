# Los Angeles 3D

A photorealistic, flyable 3D Los Angeles in the browser. It is built with [CesiumJS](https://cesium.com/platform/cesiumjs/) and Google Photorealistic 3D Tiles, and is a plain static site with no build step.

**Features:**
- Landmark fly-tos: Santa Monica Pier, Venice, the Getty, Century City, Hollywood, the Hollywood Sign, Griffith Observatory, Downtown and LAX.
- A guided flyover tour.
- Day, golden hour and night modes.
- Moving freeway traffic on the I-10, US-101, I-405, I-110 and PCH, plus boats in the bay.
- Deep links such as `#hollywood-sign`.

## 1. Get a Google Maps API key
1. Go to [Google Cloud Console](https://console.cloud.google.com/), create a project and turn on billing. The Map Tiles API has a monthly free allowance.
2. Under **APIs & Services → Library**, enable **Map Tiles API**.
3. Under **APIs & Services → Credentials**, click **Create credentials → API key**.
4. Edit the key and set these restrictions:
   - **Application restrictions → Websites:** add `http://localhost:5180/*` and `https://YOUR-GITHUB-USERNAME.github.io/*`.
   - **API restrictions:** allow only **Map Tiles API**.
5. Optional but recommended: set a budget alert under **Billing → Budgets & alerts**.
6. Paste the key into `config.js`:
   ```js
   window.LA3D = { googleMapsKey: "AIza..." };
   ```

The key is visible in the page source; that is normal for browser map keys. The website restriction is what stops anyone else from using it.

## 2. Run it locally
From the folder above `la-3d`:
```bash
powershell -ExecutionPolicy Bypass -File tools\serve.ps1 -Root la-3d -Port 5180
```
Then open http://localhost:5180/.

## 3. Publish on GitHub Pages
No Git install is needed:
1. Sign in at [github.com](https://github.com) and create a new **public** repository, e.g. `la-3d`.
2. Click **Add file → Upload files** and drag in all 8 files inside the `la-3d` folder (it has no subfolders). Then commit.
3. Go to **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, and save.
4. After a minute the site is live at `https://YOUR-GITHUB-USERNAME.github.io/la-3d/`.

## Controls
| Action | Mouse |
| --- | --- |
| Pan / move | Left-drag |
| Zoom | Scroll, or right-drag |
| Tilt and rotate | Ctrl + left-drag, or middle-drag |
| Stop the tour or orbit | Esc, or any drag |

The **Quality** button (bottom right) switches the tile detail level and render resolution; Low is the default on phones.

## Files
| File | What it does |
| --- | --- |
| `index.html` | Page, UI and styles |
| `config.js` | Your Google Maps API key |
| `app.js` | Viewer, tiles, camera flights, time of day, labels |
| `landmarks.js` | Landmark positions, camera framing, the tour order and night lights |
| `tour.js` | Guided flyover |
| `traffic.js` | Cars, boats, the Ferris wheel and night lights |
| `routes.js` | Freeway paths (generated by `tools/build-routes.ps1` from OpenStreetMap) |

**Making cars sit exactly on the roads:** route heights come from a 90 m elevation model, so on elevated sections cars can float a little or dip under the surface. Open `http://localhost:5180/?bake` and wait for it to sample the real 3D surface (a few minutes), then download the new `routes.js` and replace the one in this folder.
