Add a Google Maps API key to see the city

This page streams Google's Photorealistic 3D Tiles, which need your own key.
  1. In Google Cloud Console, create a project and turn on billing.
  2. Enable the Map Tiles API, then create an API key under APIs & Services → Credentials.
  3. Restrict the key to the Map Tiles API and to HTTP referrers http://localhost:5180/* and https://<your-username>.github.io/*.
  4. Paste it into config.js as googleMapsKey and reload.
